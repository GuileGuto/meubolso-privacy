Política de Privacidade — Meu Bolso

Última atualização: maio de 2026

Resumo simples: O Meu Bolso lê suas notificações bancárias apenas para detectar gastos automaticamente. Todos os seus dados ficam armazenados somente no seu próprio dispositivo. Não coletamos, não vendemos e não compartilhamos seus dados financeiros com ninguém.

1. Quem somos

O Meu Bolso é um aplicativo de controle financeiro pessoal desenvolvido para ajudar usuários a acompanhar seus gastos automaticamente através da leitura de notificações bancárias.

2. Quais dados o app acessa

2.1 Notificações

O Meu Bolso solicita permissão para acessar as notificações do seu dispositivo (android.permission.BIND_NOTIFICATION_LISTENER_SERVICE). Essa permissão é usada exclusivamente para:

  • Ler notificações de aplicativos bancários que você utiliza
  • Extrair automaticamente informações de transações financeiras (valor, estabelecimento)
  • Registrar gastos e entradas no seu histórico pessoal

O app não lê notificações de redes sociais, mensagens, e-mails ou qualquer outro tipo de aplicativo que não seja bancário.

2.2 Dados financeiros

Os seguintes dados podem ser registrados localmente no seu dispositivo:

  • Valor de transações detectadas em notificações bancárias
  • Nome do estabelecimento ou destinatário de transferências
  • Categoria do gasto (alimentação, transporte, etc.)
  • Data e hora da transação
  • Gastos fixos cadastrados manualmente pelo usuário

2.3 Chave de API (opcional)

Se o usuário optar por utilizar análise por inteligência artificial, pode configurar uma chave de API do Google Gemini. Essa chave é armazenada de forma criptografada no dispositivo usando EncryptedSharedPreferences e é usada apenas para enviar o texto de notificações bancárias ao serviço do Google Gemini para análise. Consulte a Política de Privacidade do Google para entender como o Google trata esses dados.

3. Como os dados são armazenados

Todos os seus dados financeiros são armazenados exclusivamente no seu dispositivo, em um banco de dados local (SQLite via Room). O Meu Bolso:

  • ✅ Não possui servidores próprios
  • ✅ Não envia seus dados financeiros para a internet
  • ✅ Não sincroniza dados com a nuvem
  • ✅ Não cria contas de usuário
  • ✅ Não coleta dados analíticos ou de uso

Se você desinstalar o aplicativo, todos os seus dados serão permanentemente removidos do dispositivo.

4. Compartilhamento de dados

O Meu Bolso não compartilha seus dados com terceiros, exceto nos casos abaixo, que dependem de ação explícita do usuário:

  • Google Gemini API (opcional): Se o usuário configurar uma chave de API, o texto das notificações bancárias é enviado ao Google para análise. O usuário pode desativar essa funcionalidade a qualquer momento nas configurações do app.

5. Segurança

Adotamos as seguintes medidas de segurança:

  • Autenticação biométrica (digital, PIN ou padrão) para acesso ao app
  • Chave de API armazenada com criptografia AES-256 via EncryptedSharedPreferences
  • Nenhum dado é transmitido sem consentimento explícito do usuário

6. Seus direitos

Você tem total controle sobre seus dados:

  • Revogar acesso às notificações: Configurações do Android → Notificações → Acesso especial
  • Excluir um gasto: Deslize o item para a esquerda na lista de transações
  • Excluir todos os dados: Desinstale o aplicativo
  • Desativar análise por IA: Configurações → remova a chave de API

7. Crianças

O Meu Bolso não é destinado a menores de 18 anos e não coleta intencionalmente dados de crianças.

8. Alterações nesta política

Podemos atualizar esta Política de Privacidade periodicamente. Notificaremos sobre mudanças significativas por meio de uma atualização do aplicativo na Play Store. O uso continuado do app após as alterações constitui sua aceitação da nova política.

9. Contato

Se você tiver dúvidas sobre esta Política de Privacidade ou sobre o tratamento dos seus dados, entre em contato pelo e-mail disponível na página do aplicativo na Google Play Store.
